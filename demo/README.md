# نسخه‌ی نمایشی «جریان»

نسخه‌ای از همین سایت برای نشان دادن به خریدار: **فقط نمای بیننده**، **داده‌ی ساختگی** (منابع و اشخاص ساختگی، موضوعات واقعی‌نما)، **ورود با رمز** و بدون هیچ اتصالی به سامانه‌ی واقعی. کد سایت اصلی دست نمی‌خورد؛ همه‌ی تفاوت‌ها در همین پوشه‌اند.

## ساخت

```
npm run demo:codes   # یک‌بار: ۵ رمز → فایل متنی روی دسکتاپ؛ هش‌ها در demo/.local (بیرون از گیت)
npm run demo:media   # تصویرها و PDFهای نمونه (پس از تغییر محتوا)
npm run demo:build   # داده + ساخت + بررسی نشت → dist-demo/ و dist-demo.zip
npm run demo:fetch   # (اختیاری) آخرین عکس فوری داده‌ی واقعی → demo/build/real
npm run demo:serve   # پیش‌نمایش محلی http://localhost:8787 (رمز آزمایشی فقط محلی: JR-TEST-0000)
```

`demo:build` اگر در خروجی نشانی سوپابیس واقعی، کلید، گیت‌هاب، کد پنل مدیریت یا نام و نشانی نهاد مسئول پیدا کند، متوقف می‌شود (`tools/pack.mjs`). اگر متنی از صفحه‌ی اصلی که `vite.demo.config.js` عوض می‌کند تغییر کرده باشد، ساخت با پیام روشن متوقف می‌شود.

## داده‌ی واقعی (عکس فوری)

1. گیت‌هاب ← Actions ← «Demo snapshot» ← Run workflow (یا `gh workflow run demo-snapshot.yml --ref main`). فقط خواندن؛ چیزی در سامانه عوض نمی‌شود.
2. `npm run demo:fetch` خروجی را می‌گیرد و با کلید خصوصی `demo/.local/snapshot-private.pem` باز می‌کند (خروجی رمزنگاری‌شده است چون ریپو عمومی است؛ گم شدن کلید = ساخت جفت کلید تازه و جایگزینی `demo/snapshot-key.pub.pem`).
3. `npm run demo:build` — اگر `demo/build/real` باشد پایه داده‌ی واقعی است و هر بخشی که داده‌ی واقعی ندارد (`merge-real.mjs`) با ساختگی پر می‌شود؛ اخبار منتخب/پرونده/خبرنامه اگر تحلیل هوش مصنوعی کهنه باشد از خوشه‌بندی خبرهای واقعی ساخته می‌شوند. تب «رهبر انقلاب» هرگز ساختگی نمی‌شود (بدون داده‌ی واقعی پنهان). فقط ساختگی: `node demo/data/generate.mjs --fake`.

## اجزا

| فایل | کار |
|---|---|
| `vite.demo.config.js` | ساخت: `config.js` → `src/config.demo.js`، `admin/admin.js` → ماژول خالی، ویرایش متن‌های HTML، حذف توضیحات HTML، کپی فایل‌ها |
| `src/shim.js`، `src/pgrest.js` | پیش از برنامه: پاسخ به درخواست‌های «سوپابیس» از داده‌ی نمایشی (فیلتر، مرتب‌سازی، شمارش)، ورود از راه `api.php`، جلو بردن زمان‌ها تا «امروز» همیشه امروز باشد، غیرفعال کردن پیوندهای بیرونی |
| `data/content-*.mjs`، `data/generate.mjs` | محتوای ساختگی و ساخت جدول‌ها → `build/data.json` |
| `tools/media.mjs` | جلد روزنامه‌ها، جلد و PDF بسته‌ها، داشبوردهای مدارس، تصویر پست‌ها، نشان منابع |
| `server/api.php` | روی هاست: بررسی رمز، اعتبار ۱۰ روز از نخستین ورود، باطل شدن رمز استفاده‌نشده پس از ۶۰ روز، قفل ۱۵ دقیقه‌ای پس از ۵ اشتباه، فرستادن داده فقط پس از ورود، گزارش `private/report.txt` |
| `tools/serve.mjs` | شبیه‌سازی `api.php` برای پیش‌نمایش بدون PHP |

تب «رهبر انقلاب» در بخش مواضع عمداً پنهان است (`hidden_sections`) تا هیچ سخن ساختگی به ایشان نسبت داده نشود.

## بارگذاری روی هاست (پارس‌پک، cPanel/DirectAdmin)

1. هاست لینوکس با PHP ۷٫۴ یا بالاتر، و گواهی SSL رایگان (Let's Encrypt) برای دامنه/زیردامنه فعال باشد.
2. File Manager ← پوشه‌ی `public_html` (یا پوشه‌ی زیردامنه) ← Upload ← فایل `dist-demo.zip` ← روی آن راست‌کلیک ← Extract.
3. سایت را باز کنید و با یکی از رمزها وارد شوید.
4. گزارش استفاده از رمزها: File Manager ← `private/report.txt`.

به‌روزرسانی: `npm run demo:build` و همین مراحل؛ پیش از Extract فایل‌های قبلی را **به‌جز** `private/state.php` پاک کنید (وضعیت رمزها در آن است). رمز تازه: `npm run demo:codes -- --new` (رمزهای قبلی باطل می‌شوند).
