# فهرست امکانات سامانه جریان

فهرست امکانات «جریان» در دو بخش **غیرفنی** (آنچه کاربر و مدیر می‌بینند) و **فنی** (معماری، جمع‌آوری داده، هوش مصنوعی، پایگاه داده، امنیت، پایش)، در یک فایل: `فهرست امکانات سامانه جریان.zip`

**لینک دانلود (همیشه آخرین نسخه):**

## محتوا (داخل زیپ، پوشه‌ی «فهرست امکانات سامانه جریان»)

| فایل | کاربرد |
|---|---|
| `فهرست امکانات سامانه جریان.pdf` | نسخه‌ی چاپی و قابل ارسال (A4، با جلد و فهرست مطالب) |
| `فهرست امکانات سامانه جریان.html` | همان متن برای مرورگر — روی گوشی خواناست و بدون اینترنت کار می‌کند (فونت داخل خودش) |
| `فهرست امکانات سامانه جریان.md` | متن ساده‌ی قابل ویرایش |
| `README-FA.txt` | راهنمای کوتاه |

## به‌روزرسانی (قاعده‌ی همیشگی — خواست کاربر، مهر ۱۴۰۵)

هر تغییری که امکانی را **اضافه، حذف یا عوض** کند (بخش/تب/ابزار مدیر تازه، کالکتور یا تابع تازه، تغییر محدودیت‌ها) → **در همان PR**:

1. متن اصلی `feature-kit/امکانات سامانه جریان.md` ویرایش شود (`{{VERSION}}` و `{{DATE}}` خودکار پر می‌شوند).
2. بعد از بالا بردن `APP_VERSION`، از ریشه‌ی ریپو اجرا شود:
   `NODE_PATH=/opt/node22/lib/node_modules node feature-kit/tools/build.js`
   (پیش‌نمایش صفحه‌های PDF: `OUT=<پوشه>` به اول دستور اضافه شود.)
3. زیپ ساخته‌شده جایگزین فایل ریپو می‌شود.

تغییر فقط ظاهری یا رفع باگ که امکانی را عوض نمی‌کند، به‌روزرسانی لازم ندارد.

## ابزار

- `tools/build.js` — مبدل کوچک markdown (تیتر `#`/`##`، فهرست `-` با تورفتگی ۲ فاصله، `**پررنگ**`، ``کد``، `---`) → HTML مستقل با فونت IRANSansX و لوگوی سایت → PDF با Chromium (Playwright) → زیپ با `zipfile` پایتون.
