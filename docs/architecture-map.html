قاعده‌های امنیت و نظم

  • هیچ دستگیره‌ی درون HTML (onclick=…)؛ هر دکمه با addEventListener یا delegation با data-*.
  • هر متن بیرونی پیش از innerHTML با escHtml، و هر لینک با safeUrl.
  • هیچ اسکریپت یا فونت از CDN؛ Chart.js، jsPDF و html2canvas محلی و فقط هنگام نیاز.

نسخه و کش

  • شماره‌ی نسخه: APP_VERSION در core/config.js + دو span.app-version در HTML.
  • سرویس‌ورکر sw.js: فایل ثابت cache-first، صفحه network-first.
  • عوض شدن فایل ثابتی با همان نام (تصویر، آیکون) = شماره‌ی CACHE بالا برود.

سمت سرور (Supabase)

پایگاه داده و ورود

  • db/schema.sql + migrationهای شماره‌دار (تا 053)، همه دستی در SQL Editor؛ schema.sql روی پروژه‌ی زنده دوباره اجرا نشود.
  • ورود: کد ملی + کد یک‌بارمصرف پیامکی (otp_request/login_otp) یا رمز مدیر همراه کد ملی (login_admin)؛ login(password) برای جمع‌آورنده‌ها و ورود اضطراری. خروجی JWT با نقش.
  • کد ملی خام ذخیره نمی‌شود (HMAC در جدولی بدون دسترسی).
  • تابع security definer تازه: چک نقش در بدنه + revoke … from anon, authenticated.

Edge Functions

  • translate ترجمه‌ی یک پست یا یافته
  • news-insights خوشه‌بندی خبرها و «اخبار منتخب»
  • extract-post-keywords کلیدواژه‌ها و فیلتر بخش‌ها
  • run-job اجرای دستی، وضعیت و گزارش کارها
  • notify هشدار ایمیلی و گزارش روزانه
  • _shared/ احراز هویت، هوش مصنوعی، خوشه‌بندی، فهرست کارها

نسخه‌ی نمایشی (demo/)

همین فرانت‌اند برای نشان دادن به خریدار: فقط نمای بیننده، بدون پنل مدیریت و بدون اتصال به سوپابیس. در ساخت، core/config.js و admin/admin.js جایگزین می‌شوند و demo/src/shim.js به درخواست‌ها از یک فایل داده جواب می‌دهد (عکس فوری رمزنگاری‌شده‌ی داده‌ی واقعی، بخش‌های خالی با داده‌ی ساختگی). ورود را demo/server/api.php روی هاست بررسی می‌کند. کد سایت اصلی برای دمو تغییری نمی‌کند.

برنامه‌ی آینده: دو سرور

تا سایت در قطعی اینترنت بین‌الملل هم از داخل در دسترس بماند و منابع فیلترشده هم رصد شوند. API سازگار با PostgREST می‌ماند تا فرانت‌اند فقط نشانی را عوض کند.

سرور ایران (اصلی)سایت، پایگاه داده، فایل‌ها، ورود پیامکی؛ ایتا، بله، سایت‌های ایرانی، روزنامه‌ها، هوش مصنوعی داخلی؛ زمان‌بندی با crontab خودِ سرور
⇄ارسال مستقیم یا دریافت، صف یک‌هفته‌ای، بسته‌ی رمزنگاری‌شده‌ی دستی
سرور خارج (فقط جمع‌آوری)تلگرام و رسانه‌ها، سایت‌ها و خوراک‌های خارجی، بخش خارجی خزنده؛ کاربر هرگز مستقیم به آن وصل نمی‌شود
