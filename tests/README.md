# آزمون‌های خودکار سایت

آزمون‌های مرورگر (Playwright) در `tests/e2e` هستند و با **داده‌ی ساختگی** کار می‌کنند؛ هیچ درخواستی به سوپابیس واقعی نمی‌رود (`support/mock-supabase.js`).

```bash
npm install          # یک‌بار
npm test             # همه‌ی آزمون‌ها، روی رایانه (1366px) و گوشی (390px)
npm test -- -g "مدیر"   # فقط آزمون‌هایی که نامشان «مدیر» دارد
npm run test:report  # گزارش آخرین اجرا (با عکس و trace آزمون‌های ناموفق)
npm run test:unit    # آزمون‌های واحد هسته (Vitest، چند ثانیه)
npm run lint         # بررسی ایستای کد (ESLint)
```

- `login.spec.js` — ورود با کد ملی و پیامک، انتخاب روش ورود مدیر، ورود اضطراری.
- `sections.spec.js` — هر بخش و تب برای بیننده و مدیر بدون خطای صفحه و بدون سرریز افقی باز می‌شود، و بیننده به بخش‌های مدیریت راه ندارد.
- `interactions.spec.js` — منوی بخش‌ها، تب‌ها و دکمه‌ی برگشت، جست‌وجو، صفحه‌بندی، فید یک چهره، خروج.
- `news.spec.js` — «اخبار و رویدادها»: هر تب با دکمه‌ی خودش، «همه ←» ادعاها، نمای فهرستی/چندستونه، «نمایش بیشتر»، ترجمه (با Edge Function ساختگی) و ویرایش کلیدواژه‌ی مدیر.
- `news-tabs-extra.spec.js` — زیرتب‌های دیگر «اخبار و رویدادها»: شاخص موج‌ها، «افزودن به منتخب»، روزنامه‌ها و نمایش بزرگ جلد، پرونده‌های موضوعی، پنل خبرنامه‌ی مدیر (پیشنهاد، حذف، جست‌وجو، افزودن، انتشار) و دانلود PDF خبرنامه.
- `people-cyber.spec.js` — «کنشگری مجازی»، «یادداشت‌ها» و «مواضع مراجع و علماء»: «نمایش بیشتر» پست‌ها و فید منبع، باز کردن منبع از گالری و برگشت، فید یک کانال از جدول «افراد و مجموعه‌ها» و «نمایش همه‌ی کانال‌ها»، تب «بسته‌های تحلیلی»، تب‌های مواضع و جابه‌جایی ظرف مشترک گالری.
- `ui-components.spec.js` — اجزای رابط (`design/src/ui`): همه‌ی گزینه‌های منوی بخش‌ها و منوی مدیریت، بستن پنجره با ×، «انصراف»، کلیک بیرون و Esc، نمایشگر سند (ورق زدن، شماره‌ی صفحه، بزرگ‌نمایی)، دکمه‌ی «فیلترها»ی گوشی، «بالای صفحه».
- `listeners.spec.js` — دکمه‌هایی که از `onclick` درون HTML به `addEventListener` منتقل شده‌اند: صفحه‌بندی، مرتب‌سازی جدول روی گوشی، «نمایش همه/بیشتر»، ویرایش سایت خزنده. داده‌ی ساختگی یک جدول برای یک آزمون: `test.use({ mockData: { login_events: [...] } })`.

آزمون‌های واحد (`tests/unit`) تابع‌های حساس `design/src/core` را بدون مرورگر می‌سنجند: escape متن و لینک امن، جست‌وجوی فارسی، تبدیل تاریخ شمسی (هر روز ۱۴۰۰ تا ۱۴۱۰ در برابر تقویم خودِ مرورگر)، مرز «امروز/دیروز» تهران و فیلتر زمان فیدها، کد ملی و شماره‌ی موبایل؛ `import-cycles.test.js` بررسی می‌کند ماژول‌ها import چرخه‌ای نداشته باشند، `app-back-refs.test.js` بررسی می‌کند ماژول‌های `features/` از app.js فقط تابع import کنند (چرخه‌ی import امن بماند)، و `inline-handlers.test.js` بررسی می‌کند فهرست موقت تابع‌های سراسری بالای `app.js` دقیقاً همان‌هایی باشد که `onclick`ها صدا می‌زنند.

هر آزمون مرورگر اگر خطای جاوااسکریپت یا `console.error` در صفحه ببیند ناموفق می‌شود. بخش یا تب تازه → به فهرست `sections.spec.js` اضافه شود. هر سه (lint، واحد، مرورگر) روی گیت‌هاب با هر PR به شاخه‌ی زنده و پیش از هر انتشار اجرا می‌شوند (`.github/workflows/tests.yml`).
