# آزمون‌های خودکار سایت

آزمون‌های مرورگر (Playwright) در `tests/e2e` هستند و با **داده‌ی ساختگی** کار می‌کنند؛ هیچ درخواستی به سوپابیس واقعی نمی‌رود (`support/mock-supabase.js`).

```bash
npm install          # یک‌بار
npm test             # همه‌ی آزمون‌ها، روی رایانه (1366px) و گوشی (390px)
npm test -- -g "مدیر"   # فقط آزمون‌هایی که نامشان «مدیر» دارد
npm run test:report  # گزارش آخرین اجرا (با عکس و trace آزمون‌های ناموفق)
```

- `login.spec.js` — ورود با کد ملی و پیامک، انتخاب روش ورود مدیر، ورود اضطراری.
- `sections.spec.js` — هر بخش و تب برای بیننده و مدیر بدون خطای صفحه و بدون سرریز افقی باز می‌شود، و بیننده به بخش‌های مدیریت راه ندارد.
- `interactions.spec.js` — منوی بخش‌ها، تب‌ها و دکمه‌ی برگشت، جست‌وجو، صفحه‌بندی، فید یک چهره، خروج.

هر آزمون اگر خطای جاوااسکریپت یا `console.error` در صفحه ببیند ناموفق می‌شود. بخش یا تب تازه → به فهرست `sections.spec.js` اضافه شود. روی گیت‌هاب با هر PR به شاخه‌ی زنده اجرا می‌شوند (`.github/workflows/tests.yml`).
