## به‌روزرسانی بسته (قاعده‌ی همیشگی)

پوشه‌های ۰۱ تا ۰۷ **فقط چیزهایی را دارند که همین حالا در سایت دیده می‌شوند**. هر تغییری در سایت که یکی از اجزای بسته را **عوض، اضافه یا حذف** کند، در همان کار در بسته هم اعمال شود و زیپ دوباره ساخته و جایگزین همین فایل شود:

- جزء عوض شد → نسخه‌ی تازه جایگزین شود (نسخه‌ی قبلی اگر ارزش مرجع دارد → `08-previous-designs`).
- جزء **از سایت حذف شد** → از پوشه‌ی اصلی به `08-previous-designs` برود (پاک نشود) و از README-FA و تصویر فهرست هم برداشته شود.
- جزء تازه در سایت (آیکون، تصویر، رنگ، متن) → به پوشه‌ی خودش اضافه شود.
- نگاشت: لوگو/`design/icons/*` → `01-logo` | `design/images/*` → `02-illustrations` | آیکون‌های خطی (`TAB_ICONS`، ستون کناری `.sn-ic`، `.wl-why`، ابزارهای نوار بالا و ستون) → `03-icons` (سه نسخه: svg-peach، svg-white، png-peach — `icons-png.js`) | رنگ‌ها → `04-colors` (هر سه فایل) | فونت → `05-fonts` | تغییر ظاهری صفحه‌های داخل اسکرین‌شات‌ها → `06-screenshots` | متن‌ها (شعار، عرصه‌ها، منو، تب‌ها، …) → `07-text`.
- بعد از هر تغییر: `README-FA.txt` و `00-فهرست اجزای بسته.png` هم به‌روز شوند (و کپی‌اش `brand-kit/فهرست اجزای بسته.png`).

روش: زیپ فعلی را باز کن، تغییرها را اعمال کن، دوباره زیپ کن (نام پوشه‌ی داخلی و نام فایل همان «بسته گرافیکی سامانه جریان» بماند؛ با `zipfile` پایتون تا نام‌های فارسی پرچم UTF-8 بگیرند).

## ابزارها (`tools/`)

اسکریپت‌هایی که اجزای بسته با آن‌ها ساخته شده‌اند (Python + Playwright؛ `NODE_PATH=/opt/node22/lib/node_modules`، مرورگر `/opt/pw-browsers/chromium`). مسیرها با متغیر محیطی/نسبی‌اند؛ قبل از اجرا نگاهی به بالای هر فایل بینداز.

- `logotype-trace.js` → `logotype-icons.js` → `logotype-kit.js` (۶.۱.۰، Node + `sharp` و `potrace`) — برداری کردن لوگوتایپ از PNG تخت کاربر (`node logotype-trace.js <png> path.txt`)، ساخت فایل‌های `design/icons` و favicon.ico (`node logotype-icons.js path.txt <out>`)، و پوشه‌ی تازه‌ی `01-logo` بسته (`node logotype-kit.js path.txt <ریشه‌ی بسته> design/icons <out>`).
- (لوگوی قبلی) `flowmark.py` — هندسه‌ی نشان (مدار باز، شهاب باریک‌شونده با ماسک، سه ستون) روی بوم ۲۸۸؛ پایه‌ی همه‌ی نسخه‌های لوگو.
- `build.py` (+ `build_text.py`) — نشان‌ها، لایه‌های انیمیشن و لوگوهای کامل عمودی/افقی؛ متن فارسی با HarfBuzz به منحنی تبدیل می‌شود (`pip install uharfbuzz fonttools`؛ env: `K`=پوشه‌ی باز بسته، `OUT`، `LK=.`). `png.js` خروجی PNG (env `O`)، `lockup-preview.js` تصویر پیش‌نمایش.
- `intro.py` — موشن لوگو (html)؛ `V=light` نسخه‌ی زمینه‌ی روشن. `rec.js`/`recl.js` فیلم webm، `seq.js`/`seql.js` دنباله‌ی ۹۰ فریم PNG شفاف (env `OUT`).
- `site_icons.py` — آیکون‌های سایت (`design/icons`: jarian-mark.svg، icon.svg، icon-maskable.svg)؛ PNGها از روی همین SVGها.
- `icons_spec.py` + `icons-png.js` — آیکون‌های خطی اصلاح‌شده (مهر ۱۴۰۵) و خروجی PNG ۵۱۲.
- `screenshots.js` — اسکرین‌شات‌ها با داده‌ی موک (سرور محلی روی پورت ۸۷۶۵، env `SP`).
- `contents_gen.py` + `contents-shot.js` — تصویر فهرست اجزای بسته (`00-فهرست اجزای بسته.png`): `K=<ریشه‌ی بسته> python -X utf8 contents_gen.py` و بعد `node contents-shot.js` در همان پوشه (روی ویندوز هم؛ مرورگر لینوکسی با `PW_CHROMIUM`).
