## به‌روزرسانی بسته (قاعده‌ی همیشگی)

هر تغییری در سایت که یکی از اجزای بسته را عوض کند، باید در همان کار در بسته هم جایگزین شود و زیپ دوباره ساخته و جایگزین همین فایل شود:

- لوگو/آیکون‌های سایت (`design/icons/*`) → `01-logo` (+ `previous-site-icon` اگر لوگو عوض شد)
- آیکون‌های خطی (`TAB_ICONS`، آیکون‌های آمار هرو در `renderDashHeroStats`، `.pkg-parts`، `.qn-capsule`) → `03-icons` (سه نسخه: svg-peach، svg-white، png-peach)
- تصویرهای `design/images/*` → `02-illustrations`
- قوس‌ها/شهاب صفحه‌ی نخست (`dom-orbit`/`pkg-orbit`) → `04-shapes`
- رنگ‌ها → `05-colors` (هر سه فایل) | فونت → `06-fonts` | متن‌ها (شعار، عرصه‌ها، تب‌ها، …) → `08-text`
- تغییر ظاهری صفحه‌های داخل اسکرین‌شات‌ها → `07-screenshots` دوباره گرفته شود
- بعد از هر تغییر: `README-FA.txt` و `00-فهرست اجزای بسته.png` هم به‌روز شوند (و کپی‌اش `brand-kit/فهرست اجزای بسته.png`).

روش: زیپ فعلی را باز کن، فقط اجزای تغییرکرده را جایگزین کن، دوباره زیپ کن (نام پوشه‌ی داخلی و نام فایل همان «بسته گرافیکی سامانه جریان» بماند؛ با `zipfile` پایتون تا نام‌های فارسی پرچم UTF-8 بگیرند).

## ابزارها (`tools/`)

اسکریپت‌هایی که اجزای بسته با آن‌ها ساخته شده‌اند (Python + Playwright؛ `NODE_PATH=/opt/node22/lib/node_modules`، مرورگر `/opt/pw-browsers/chromium`). مسیرها با متغیر محیطی/نسبی‌اند؛ قبل از اجرا نگاهی به بالای هر فایل بینداز.

- `flowmark.py` — هندسه‌ی نشان (مدار باز، شهاب باریک‌شونده با ماسک، سه ستون) روی بوم ۲۸۸؛ پایه‌ی همه‌ی نسخه‌های لوگو.
- `build.py` (+ `build_text.py`) — نشان‌ها، لایه‌های انیمیشن و لوگوهای کامل عمودی/افقی؛ متن فارسی با HarfBuzz به منحنی تبدیل می‌شود (`pip install uharfbuzz fonttools`؛ env: `K`=پوشه‌ی باز بسته، `OUT`، `LK=.`). `png.js` خروجی PNG (env `O`)، `lockup-preview.js` تصویر پیش‌نمایش.
- `intro.py` — موشن لوگو (html)؛ `V=light` نسخه‌ی زمینه‌ی روشن. `rec.js`/`recl.js` فیلم webm، `seq.js`/`seql.js` دنباله‌ی ۹۰ فریم PNG شفاف (env `OUT`).
- `site_icons.py` — آیکون‌های سایت (`design/icons`: jarian-mark.svg، icon.svg، icon-maskable.svg)؛ PNGها از روی همین SVGها.
- `icons_spec.py` + `icons-png.js` — آیکون‌های خطی اصلاح‌شده (مهر ۱۴۰۵) و خروجی PNG ۵۱۲.
- `screenshots.js` — اسکرین‌شات‌ها با داده‌ی موک (سرور محلی روی پورت ۸۷۶۵، env `SP`).
- `contents_gen.py` + `contents-shot.js` — تصویر فهرست اجزای بسته (`00-فهرست اجزای بسته.png`).
